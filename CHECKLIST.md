# Відповідність завданню — без обіцянки оцінки

| Пункт | Що підготовлено | Що лишилося |
|---|---|---|
| 1.1 FlameGraph | profile.sh, flamegraph.sh, два SVG | показати побудову на захисті |
| 1.2 Інтерпретація | report.md, DEFENSE.md | пояснити своїми словами |
| 2.1 time | 10 реальних логів time -l | продемонструвати macOS-аналог |
| 2.2 perf stat | instructions/cycles/IPC, faults, switches | cache misses немає; зазначити межі заміни |
| 2.3 record/report | sample.txt, дерево й підсумок функцій | пояснити заміну perf на sample |
| 3.1 Енергія системи | скрипт CPU+GPU+ANE | це не весь Mac; потрібен запуск та погодження методу/ватметр |
| 3.2 Енергія програми | оцінка приросту відносно фону | потрібен запуск; не називати прямим вимірюванням процесу |
| 4.1 Асемблер | O0/O3 і пояснення | показати конкретні інструкції |
| 4.1.1 SIMD | фактичні NEON add.4s/orr.4s | пояснити 4 елементи у векторі |
| 4.2 Час і показники | медіани 5 запусків | готово для пояснення |
| 4.3 Зміни FlameGraph | порівняння двох графіків | пояснити, чому схожість не суперечить прискоренню |
| 4.4 Енергія після | автоматичне зведення у energy.py | реальні дані ще потрібні |
| GitHub | код і докази підготовлені | перевірити актуальність опублікованої версії |
| Відео | сценарій і команди | записати, перевірити звук/камеру, завантажити |

Дозвіл на macOS-аналоги не є автоматичним погодженням будь-якої методики
енерговимірювання. Пункти 3.1/3.2 можуть потребувати окремого уточнення
з викладачем. Не обіцяємо 25 балів без його оцінювання.
