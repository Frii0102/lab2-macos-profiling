# Почати тут: результати готові до запису захисту

Зарядку можна підключити. Новий довгий тест батареї не потрібний.
Пароль адміністратора вводити не потрібно. Збережені вимірювання та їхні
обмеження — у report.md і results/energy-final/summary.md.

## 1. Відкрити матеріали

У Finder відкрий теку lab2-mac. Прочитай DEMO_STEPS.md та DEFENSE.md.
Звіт можна зручно показувати у браузері через GitHub:
https://github.com/Frii0102/lab2-macos-profiling

## 2. Відкрити Terminal

Натисни Command + пробіл, введи Terminal і натисни Enter.
Введи `cd ` (пробіл після cd), перетягни теку lab2-mac із Finder у Terminal,
натисни Enter. Так Terminal перейде саме до проєкту.
Потім введи:

```bash
bash demo.sh
```

Скрипт зупиняється між етапами. Читай пояснення, говори й натискай Enter,
коли готова до наступного кроку. Початкові результати звіту не перезаписуються.
Під час першої репетиції перевір, що sample працює і SVG відкривається.
При помилці не продовжуй удавати успіх: збережи повідомлення.

## 3. Запис у Zoom на комп’ютер

1. Відкрий настільний Zoom і увійди. Натисни New Meeting / Нова конференція.
2. Увімкни мікрофон і камеру; при запиті обери Join with Computer Audio.
3. Натисни Share / Демонстрація, вибери екран із Terminal і браузером.
   Закрий особисті вікна, вимкни сповіщення. Збільш текст Terminal через Command + плюс.
4. У More / Ще знайди Record / Запис, обери запис на комп’ютер, не хмару.
5. Зроби тест на 20 секунд: скажи кілька слів, покажи Terminal.
   Зупини запис, заверши конференцію й дочекайся конвертації.
6. Переглянь отриманий MP4: мають бути екран, голос і твоя камера.
   Якщо чогось немає, виправ налаштування до основного запису.
7. Створи нову конференцію і запиши повний захист за DEMO_STEPS.md.
   Не вмикай Optimize for video sharing для коду — це може погіршити текст.
8. Наприкінці Stop Recording, End Meeting, дочекайся готового файлу.

Якщо Record відсутній: у вебналаштуваннях Zoom → Recording увімкни
Record to computer files. Для керованого університетом акаунта опцію
може блокувати адміністратор; тоді потрібен доступний акаунт чи інший засіб запису.

Офіційні інструкції:
[запис](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0076922),
[налаштування](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0063640),
[демонстрація екрана](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0060596).

## 4. Здача

Перевір відео: початок, середину й кінець, звук, читабельність і камеру.
Завантаж на свій YouTube, наприклад із доступом за посиланням, та перевір
посилання без входу у свій акаунт. До Classroom додай GitHub і відео.
Публікація репозиторію не записує й не завантажує відео автоматично.

Важливо: аналоги macOS дозволені, але cache/branch misses тут не виміряні.
Батарея дає грубу оцінку системи; rusage — CPU-енергію процесу за обліком ОС.
Ми не обіцяємо оцінку викладача і не приховуємо AI-допомогу.
