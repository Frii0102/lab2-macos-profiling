# Що робити зараз

## 1. Енергія — потрібен пароль Mac у твоєму терміналі

```bash
bash run-energy.command
```

Команду запускати з теки проєкту. Введи пароль входу в Mac. Символи не відображаються — це нормально.
Не надсилай пароль у чат. Приблизно 4 хвилини не запускай важких програм,
не змінюй зарядку, режим живлення та яскравість. Якщо помилка — збережи її текст.
Не запускай повторно паралельно з першим вимірюванням.

Після успіху: у results/energy-ДАТА/ буде energy-summary.md.
Поки його немає, енергетична частина НЕ завершена.
Скрипт вимірює оцінки CPU+GPU+ANE, не весь Mac і не ізольовану програму.

## 2. Розібрати лише головне

- kernel.cpp: одна формула, один цикл.
- report.md: результати й пояснення.
- DEFENSE.md: що показувати й говорити.
- CHECKLIST.md: що закрито, а що потребує уточнення.

Не вчи весь асемблер: зрозумій scalar → NEON та те, чому IPC не дорівнює швидкості.

## 3. Команди для демонстрації

```bash
# Спочатку відкрити термінал у теці проєкту.
bash build.sh
./build/program_O0 10 1
./build/program_O3 10 1
bash measure.sh
bash profile.sh 0
```

Остання команда виведе новий шлях до sample.txt. Скопіюй його в команду:

```bash
bash flamegraph.sh ШЛЯХ_З_ПОПЕРЕДНЬОЇ_КОМАНДИ O0
open flamegraphs/O0.svg
```

Слово ШЛЯХ_З_ПОПЕРЕДНЬОЇ_КОМАНДИ — замінити, не вводити буквально.
Для O3 повторити `bash profile.sh 3` і побудову з назвою O3.
Графіки перезапишуться новими вимірами; збережені старі логи не видаляються.
Нові значення можуть трохи відрізнятися від звіту — це нормально.
Не демонструвати одночасно з енерговимірюванням.

## 4. Запис відео

Використай програму запису, у якій ти вже вмієш показувати екран,
мікрофон і маленьке вікно камери (наприклад Zoom). Спочатку зроби
20-секундний тест: чи видно текст, чи чути голос, чи є камера.
Закрий особисті чати й повідомлення. Пароль не вводь на записі.
Орієнтир: 8–10 хвилин за DEFENSE.md; не прискорюй команди до нечитабельності.

Після запису переглянь початок, середину та кінець. Відео потрібно
завантажити на свій YouTube або захистити роботу очно. У репозиторії відео
не з’явиться автоматично. Готове посилання перевірити без входу у свій акаунт.

## 5. Перед здачею

Перевірити енергетичний розділ і погодження меж вимірювання. Не називати
оцінку підсистем точними джоулями всієї системи чи процесу.
Після додавання нових результатів оновити звіт і GitHub.
До Classroom прикріпити GitHub + YouTube (або обрати очний захист).
